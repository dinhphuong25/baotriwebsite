# Trang Thông Báo Tạm Ngừng Hoạt Động - Rạp Phim Chill (rapphimchill.pro)

Giao diện thông báo tạm ngừng phục vụ dành cho thương hiệu **Rạp Phim Chill**, thiết kế theo nhận diện thương hiệu độc quyền (Xanh Lục Bảo Emerald Green & Đen Nhám), tối giản, sang trọng và tương thích 100% trên các thiết bị di động cũng như máy tính.

## 📂 Cấu trúc thư mục

- `index.html`: Trang thông báo tạm ngừng hoạt động (Bản quyền nội dung).
- `style.css`: File định kiểu Glassmorphism, font chữ Be Vietnam Pro & Montserrat, hiệu ứng ánh sáng nền mờ Emerald Green.
- `server.js`: Dev server Node.js chạy cục bộ port 3001.
- `go.php`: Trang chuyển hướng đếm ngược.
- `404.html`: Trang thông báo lỗi 404.
- `script.js`: File xử lý JavaScript.

## 🚀 Chạy cục bộ

```bash
node server.js
```
Truy cập: `http://localhost:3001`
